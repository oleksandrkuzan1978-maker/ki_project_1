Агент-помощник для изучения Python

Идея простого агента, который помогает находить ошибки в коде, объясняет их причины и предлагает понятные исправления.

1. Идея и назначение

Я предлагаю создать ИИ-агента для начинающего программиста. Пользователь передаёт ему код Python и, если программа завершилась с ошибкой, сообщение об этой ошибке.

Агент изучает полученные данные, выбирает подходящие инструменты проверки и предлагает исправление с объяснением.

Почему это полезно мне: во время изучения Python важно не только исправить код, но и понять причину ошибки. Такой помощник позволит разбирать затруднения и постепенно учиться находить их самостоятельно.

2. Необходимые инструменты

Инструменты агента и их назначение
Инструмент Для чего нужен
Языковая модель, например Gemini Анализирует код и сообщения об ошибках, формулирует объяснения и предлагает исправления.
Чтение Python-файлов Получает исходный код из файла, выбранного пользователем.
Модуль Python ast Проверяет синтаксис без выполнения программы. Например, помогает обнаружить пропущенное двоеточие или незакрытую скобку.
Поиск по учебным материалам Находит объяснения и примеры по теме ошибки в подготовленных конспектах.
Консольный интерфейс Позволяет указать файл, передать сообщение об ошибке, ответить на уточняющие вопросы и прочитать результат.

3. Порядок работы агента

  1. Получение задачи. Пользователь указывает файл с кодом, описывает ожидаемый результат и при необходимости передаёт сообщение об ошибке.
  2. Первичный анализ. Агент читает код и определяет, достаточно ли информации. Если проблема неясна, задаёт уточняющий вопрос.
  3. Выбор инструмента. Для проверки синтаксиса агент использует ast. Для объяснения незнакомой конструкции может обратиться к учебным материалам.
  4. Подготовка исправления. На основе кода, сообщения об ошибке и результатов проверки агент предлагает исправленный фрагмент.
  5. Повторная проверка. Агент проверяет синтаксис предложенного варианта. Если проверка обнаружила ошибку, дорабатывает решение.
  6. Объяснение результата. Пользователь получает причину ошибки, исправленный код и пояснение внесённых изменений. Исходный файл изменяется только после согласия пользователя.

4. Пример использования

Пользователь сообщает, что программа не выводит приветствие, и передаёт следующий код.

Исходный код

name = input("Введите имя: ")
print("Привет, " + Name)

Создана переменная name, а при выводе используется Name.

Исправленный код

name = input("Введите имя: ")
print("Привет, " + name)

При вводе и выводе используется одно и то же имя переменной.

Объяснение агента

Python различает строчные и прописные буквы: name и Name — разные имена. В приведённой программе переменная Name не определена, поэтому при выполнении возникнет NameError.

Что показывает этот пример: проверка через ast не обнаружит такую ошибку, поскольку синтаксис корректен. Для её выявления агент анализирует имена переменных и сообщение об ошибке. Успешная проверка синтаксиса не гарантирует правильность работы программы.

5. Почему это агент

Помощник не ограничивается одним ответом модели. Он выбирает следующий шаг в зависимости от задачи: проверяет синтаксис, ищет учебный материал или запрашивает недостающие сведения. Затем оценивает полученный результат и при необходимости повторяет проверку.

Ожидаемый результат: пользователь получает обоснованное исправление и понимает, почему оно необходимо.
